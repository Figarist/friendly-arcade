## 1. Концептуальні Шари (Architecture Layers)

Дизайн-система Friendly Arcade побудована за ієрархічною 4-шаровою моделлю, що усуває хаос у CSS та гарантує передбачуване масштабування:

```
┌──────────────────────────────────────────────────────────────┐
│  Layer 4: Доменні Панелі (Domain Layouts)                    │
│  (Сайдбари LEGO, 3D Canvas в'юпорти, піксельні сітки)        │
├──────────────────────────────────────────────────────────────┤
│  Layer 3: Складні Компоненти (Composite Components)          │
│  (.card, .arcade-modal, .hero-banner, .arcade-toast)         │
├──────────────────────────────────────────────────────────────┤
│  Layer 2: Примітиви Інтерфейсу (Atomic Primitives)           │
│  (.btn, .pill, .chip, .badge, типографіка, форми)            │
├──────────────────────────────────────────────────────────────┤
│  Layer 1: Дизайн-Токени (Design Tokens & Math)               │
│  (Кольори, поверхні, формули WCAG, радіуси, тіні, анімації) │
└──────────────────────────────────────────────────────────────┘
```

## 2. Шар 1: Дизайн-Токени та Математика Контрасту

### 2.1 Філософія кольору «Deep Midnight Arcade»
Замість нудного плоского чорного (`#000000`) або депресивного корпоративного сланцю (`#0f172a`), система використовує глибоку нічну палітру на базі синьо-фіолетового спектра:
* `--bg: #1a1a2e` — космічний ультрамарин (головне тло).
* `--bg2: #16213e` — поглиблений ультрамарин для полів вводу та заглиблених контейнерів.
* `--surface: #0f3460` — робочі плашки, шапки, панелі керування.
* `--surface2: #1a4080` — рамки та розділювачі з високою роздільною здатністю.
* `--card: #1e3a5f` — тло ігрових плиток контенту (Roblox-style).
* `--card-hover: #264d73` — стан підсвічування плитки.

### 2.2 Математика доступності WCAG AAA/AA
Розрахунок контрастності ведеться за стандартом W3C Relational Luminance:
$$\text{Contrast Ratio} = \frac{L_1 + 0.05}{L_2 + 0.05}$$

| Пара кольорів | Розрахований коефіцієнт | Стандарт WCAG | Результат |
|---|---|---|---|
| `--on-green: #06210f` на `--green: #00d26a` | **8.46:1** | AAA ($> 7:1$) | ✅ Ідеальна чіткість |
| Білий `#ffffff` на `--green: #00d26a` | **2.01:1** | Провал ($< 3:1$) | ❌ **Категорично заборонено** |
| `--on-yellow: #261b00` на `--yellow: #ffc312` | **10.54:1** | AAA ($> 7:1$) | ✅ Ідеальна чіткість |
| Білий `#ffffff` на `--yellow: #ffc312` | **1.61:1** | Провал ($< 3:1$) | ❌ **Категорично заборонено** |
| `--on-cyan: #061e38` на `--cyan: #00d2ff` | **8.85:1** | AAA ($> 7:1$) | ✅ Ідеальна чіткість |
| Білий `#ffffff` на `--red: #c02937` | **5.81:1** | AA ($> 4.5:1$) | ✅ Стандарт для кнопок |
| `--text: #ffffff` на `--card: #1e3a5f` | **8.22:1** | AAA ($> 7:1$) | ✅ Легке читання дітьми |
| `--text2: #c3dcff` на `--bg: #1a1a2e` | **12.19:1** | AAA ($> 7:1$) | ✅ М'який для очей текст |

## 3. Шар 2: Радіуси Заокруглення (Zero Magic Numbers)

У системі повністю ліквідовано випадкові значення (`50px`, `14px`, `7px`):
* `--r-xs: 6px` — мікро-чіпи, системні позначки розміром $\le 16\text{px}$.
* `--r-sm: 10px` — внутрішні елементи вводу (інпути, дропдауни).
* `--r-md: 16px` — базовий радіус карток, панелей та вікон інструментів.
* `--r-lg: 24px` — великі модальні діалоги, герой-банери, головні картки розділів.
* `--r-pill: 999px` — овальні кнопки (`.btn`), статус-пігулки (`.pill`), лічильники та аватарки.

## 4. Шар 3: Тактильна Фізика Інтерфейсу (Micro-Interactions)

Інтерфейси для дітей мають бути **пружними та відгукливими**, як справжня іграшка:
* **Ховер картки (`.card:hover`):**  
  `transform: translateY(-8px) scale(1.02);`  
  Супроводжується неоновим контуром `border-color: var(--green)` та м'яким свіченням `box-shadow: var(--shadow-glow-green)`.
* **Натискання картки (`.card:active`):**  
  `transform: translateY(-2px) scale(0.98);` — відчуття фізичного натискання клавіші.
* **Натискання кнопки (`.btn:active`):**  
  `transform: scale(0.96);` — пружна амортизація.
* **Плавність (`cubic-bezier`):**
  * `--ease-smooth: cubic-bezier(0.25, 0.8, 0.25, 1);` — плавне ковзання без ривків.
  * `--ease-bounce: cubic-bezier(0.175, 0.885, 0.32, 1.275);` — грайливий відскок (bounce).

## 5. Шар 4: Нульові Залежності та Офлайн-Безпека

1. **Жодних зовнішніх шрифтів:** Підключається безпечний стек системних шрифтів:
   ```css
   font-family: 'Segoe UI', Roboto, -apple-system, BlinkMacSystemFont, 'Helvetica Neue', Arial, sans-serif;
   ```
   Він гарантує миттєвий рендеринг без FOUT/FOIT (миготіння незавантаженого шрифту) та 0 байт мережевого трафіку.
2. **Вбудований звук Web Audio API:** Клацання, акорди та підтвердження генеруються синусоїдними та трикутними осциляторами через `AudioContext` браузера без підвантаження `.mp3` файлів.
